    Duress password

    A second password you can type at the unlock screen instead of your real master password. It never unlocks anything — it silently and permanently deletes this vault, and the app looks exactly like it did before a vault ever existed here. For situations where you might be pressured to unlock it for someone.

    Delete vault

    Permanently deletes every saved login on this device. Only this vault's data is removed — nothing else in this browser or app is touched. This can't be undone.
